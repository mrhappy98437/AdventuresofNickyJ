MailBase

A private, locally running desktop email application for managing personal Gmail accounts.

What MailBase does

MailBase is being created as a personal desktop app. It is intended for private use rather than public distribution, with a database-style interface for reading, organizing, searching, composing, sending, replying to, forwarding, and managing email.

Personal Gmail access

When a Gmail account is connected, MailBase uses Google OAuth and the Gmail API only after the account owner authorizes access. The app is designed to provide email-client functionality for the authorizing user.

Local desktop application

The MailBase application runs locally on the user's computer. This page introduces the project; it does not host the email application or email data.
